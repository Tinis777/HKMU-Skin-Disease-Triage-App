# AI-Based Skin Disease Classification & Triage System

## Project Overview
This repository contains the source code for an accessible, smartphone-based skin disease screening web application. It utilizes a lightweight **YOLOv8** architecture to classify skin lesions and an **Automated Triage Engine** to provide actionable medical referral recommendations for the general public.

## Project Structure
- **/app**: Contains the Streamlit frontend and the triage logic.
- **/models**: Contains custom PyTorch classification layers and training scripts.
- **/data**: Scripts for downloading and preprocessing PAD-UFES-20 and HAM10000 datasets.

## Tech Stack
- **AI/Backend**: PyTorch, Ultralytics YOLOv8
- **Frontend/Web**: Streamlit (Python)
- **Deployment**: TBD (Cloud-side Prototype)
